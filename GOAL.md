# Goal

Draft for AC to edit. This page changes rarely, and only by AC.

## The question

At a review date, using only what was known at that date:

1. **Measure** what each manager delivered beyond markets, as accurately as we can.
2. **Rank** managers on that measure.
3. **Check** that the ranking picks managers who go on to deliver more than the eligible universe, and avoids the worst.

Whether this improves an actual allocation is a later question.

## What counts as alpha here

- The quantity that matters is the **compounded return beyond markets** that an investor actually received. Average alpha on paper is of no interest if it does not turn into that.
- Each month, fund return = cash + markets + alpha + error. Alpha plus error is what was delivered beyond markets.
- The **ratio of alpha to error** matters. It decides how likely compounded alpha is to end positive.
- Skill is rare, it fluctuates, and it does not last for ever.

## What this project is not

- Not a search for a perfect estimator in simulation.
- Not a proof that any single manager is skilled.
- Not an allocation engine (later).
