Documentation for the production package.

| Start here | What it covers |
| --- | --- |
| [Production operating guide](app/guides/production_operations.md) | Inputs, build command, validated-run lifecycle |

Other folders:

- `app/guides/` — older framework, integration and query guides. Some carry historical banners.
- `app/published/` — documents issued outside the project.
- `app/_generated/` — function inventory and output catalogue, produced by `tools/doc_generation`.
- `app/db_construction/` — walk-forward results schema.
- `backtest/` — notes on the backtest framework.

Research documentation is no longer kept here. Current research is in the
`smc_research` repository. The September to November 2026 research pages,
including the September factor review, are preserved under
[archive/2026_autumn_research/docs/research](../archive/2026_autumn_research/docs/research/README.md).

Data files and their sources are listed in [data/README.md](../data/README.md).
