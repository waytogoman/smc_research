# Studies

One folder per study: `<yyyy-mm>_<short name>/`.

| File | What it is |
| --- | --- |
| `run.py` | The one script that produces the result. Paths come from `.env`. |
| `RESULTS.md` | One plain-English page: the question, what ran, the result in a few numbers, what it changes, and the decision asked of AC (keep, drop or park). |
| `TECHNICAL.md` | Method, formulas, settings and anything a specialist would want to check. |

Bulk output goes to the output folder on the data drive, not into git.
